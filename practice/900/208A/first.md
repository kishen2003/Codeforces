Problem Link: [codeforces.com/problemset/problem/208/A](https://codeforces.com/problemset/problem/208/A)

## Solution:

* Read the string in as input by stripping it and splitting it with WUB
* Remove all empty strings from list
* Now join the list with space and print it

### Complexity:

Time: O(n) - n is the length of the string
Space: O(n) - input string, split list

Accepted
